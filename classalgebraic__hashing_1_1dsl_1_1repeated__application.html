Detailed Description

template<concepts::ComposableHashFunction F, std::size_t N>
class algebraic_hashing::dsl::repeated_application< F, N >

Repeated Application: h^n.

Applies a hash function n times: h(h(h(...h(x)...))) Useful for creating hash stretching functions.
