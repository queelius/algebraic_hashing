Detailed Description

mod<N> is integer modulo 2^N over {+,*,^}. That is, it is a ring (mod<N>, *, +, ~, mod<N>(), mod<N>::max())

String literals for constructing common modulo equivalence classes are provided, e.g., 101_mod16 => mod<4>(5).
