Detailed Description

template<typename H>
struct hashing::perfect_hashing::phf< H >

Models the concept of a perfect hash function.

phf<H> models a perfect hash function of type Hashable(H) -> size_t where H is a hash function of type Hashable(H) -> size_t using only one level of hashing.
