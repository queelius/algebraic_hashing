Detailed Description

template<typename H>
class hashing::perfect_hashing::rphf< H >

Models the concept of a perfect hash function.

rphf<H> models a perfect hash function of type Hashable(H) -> size_t where H is a hash function of type Hashable(H) -> size_t.

This is a maximum entropy representation of a perfect hash function, since:

  • It doesn't include any information about the number of elements in the perfectly hashed set, only that it is between min() and max().
  • It doesn't contain information about which are the elements of S.
