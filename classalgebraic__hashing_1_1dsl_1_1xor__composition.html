Detailed Description

template<concepts::ComposableHashFunction F1, concepts::ComposableHashFunction F2>
class algebraic_hashing::dsl::xor_composition< F1, F2 >

Algebraic Operations DSL for Hash Functions.

XOR Composition: h₁ ⊕ h₂

This module provides an elegant domain-specific language for composing hash functions algebraically. The design philosophy follows mathematical principles where hash functions can be:

  1. Composed: f ∘ g creates a new hash function
  2. Combined: f ⊕ g combines outputs algebraically
  3. Transformed: Functions like lift, chain, repeat
  4. Analyzed: Properties like entropy, collision probability

The DSL uses operator overloading and template metaprogramming to create an intuitive mathematical syntax for hash function algebra.

Creates a new hash function that computes h₁(x) ⊕ h₂(x). This is the fundamental algebraic operation in our hash function algebra.

Mathematical properties:

  • Commutative: h₁ ⊕ h₂ = h₂ ⊕ h₁
  • Associative: (h₁ ⊕ h₂) ⊕ h₃ = h₁ ⊕ (h₂ ⊕ h₃)
  • Has identity: h ⊕ zero_hash = h
  • Self-inverse: h ⊕ h = zero_hash
