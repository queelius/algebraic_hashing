Detailed Description

template<typename Derived, typename HashType>
class algebraic_hashing::hash_function_base< Derived, HashType >

Base class for hash functions providing common interface.

This class provides a pedagogical foundation for understanding hash functions and their algebraic properties. It demonstrates key concepts:

  1. Determinism: Same input always produces same output
  2. Avalanche Effect: Small input changes cause large output changes
  3. Uniform Distribution: Outputs should be uniformly distributed
  4. Efficiency: Fast computation for practical use

The class uses CRTP (Curiously Recurring Template Pattern) to provide static polymorphism while maintaining performance.
