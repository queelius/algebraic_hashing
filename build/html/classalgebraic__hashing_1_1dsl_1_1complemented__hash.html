Detailed Description

template<concepts::ComposableHashFunction F>
class algebraic_hashing::dsl::complemented_hash< F >

Complemented Hash: ~h.

Creates a hash function that computes ~h(x) where ~ is bitwise complement. This is an involution: ~~h = h.
