Detailed Description

template<typename H>
struct algebraic_hashing::rd_phf< H >

Models the concept of a rate-distorted perfect hash function.

rd_phf<H> models a perfect hash function of type Hashable(H) -> size_t where H is a hash function of type Hashable(H) -> size_t using only one level of hashing.
