Detailed Description

template<concepts::ComposableHashFunction F1, concepts::ComposableHashFunction F2>
class algebraic_hashing::dsl::sequential_composition< F1, F2 >

Sequential Composition: h₁ ∘ h₂

Creates a hash function that computes h₁(h₂(x)). This represents function composition in the traditional sense.

Note: This typically reduces entropy since the intermediate hash creates an information bottleneck.
