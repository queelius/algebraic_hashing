Support the ability to pack a hash function into a preallocated contiguous memory space pointed by hash_packed.

Parameters
statepoints to the hash function
hash_packedpointer to the contiguous memory area used to store the hash function. The size of hash_packed must be at least hash_state_packed_size()

Support the ability to pack a hash function into a preallocated contiguous memory space pointed by hash_packed. However, the hash function type must be packed outside.
